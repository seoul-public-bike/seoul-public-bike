# 서울 공공 자전거 이용자 수요 예측 프로젝트

> 데이터 기반 수요 예측을 통해 공공 자전거 운영 효율성과 지속 가능성을 개선하는 프로젝트  
📊 머신러닝 + 시계열 분석 + 웹 서비스 구현

---

## 프로젝트 개요

서울 공공 자전거(따릉이)는 이용량이 지속적으로 증가하고 있지만,  
연간 100억 원 이상의 운영 적자가 발생하고 있습니다.

본 프로젝트는 **데이터 기반 수요 예측 모델**을 구축하여  
자전거 재배치 및 유지보수 최적화를 통해 운영 효율성을 개선하는 것을 목표로 합니다.

---

## 프로젝트 목표

- 📈 이용 패턴 분석 및 수요 예측 모델 구축  
- 🔄 자전거 재배치 및 유지보수 최적화  
- 🌍 서울·뉴욕·런던 비교 분석을 통한 운영 전략 개선

## 주요 분석 인사이트

### 시간 / 요일 패턴
- 출퇴근 시간대 (08시, 18시) 수요 집중  
- 평일 이용량이 주말보다 약 1.5배 높음  

### 기상 영향
- 기온 상승 → 수요 증가  
- 강수량 증가 → 수요 감소  

### 도시 비교
- 서울: 출퇴근 피크 가장 뚜렷  
- 뉴욕: 관광 중심 이용 비중 높음  
- 런던: 전체적으로 안정적인 수요  

### 사용자 변화
- 20대 이용자 감소 (가장 큰 하락)  
- 고령층 이용 비율 증가
